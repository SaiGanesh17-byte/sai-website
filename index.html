Up and running in minutes.

Your license is made for your laptop — and only your laptop.

  1. 1

    Download and install

    For macOS with Python 3.14. The package is locked — it runs only once your license is activated.

    Download sAI 0.2.0 for macOS

    python3 -m pip install sai-0.2.0-py3-none-any.whl
  2. 2

    Get your laptop code

    Run this in Terminal and copy the 64-character code it prints. It identifies this computer only — nothing personal.

    python3 -m sai_guard machine-id
  3. 3

    Request access

    Paste that code into the form below. Every request is reviewed personally.

  4. 4

    Activate

    Once approved, run this and paste the license from your email.

    python3 -m sai_guard activate
  5. 5

    Start building

    Type sai in any project folder. The first launch asks for your model API keys.

Questions? Answers.

Does it work on Windows or Linux?

Not yet — sAI 0.2.0 supports macOS only. Linux support is close; Windows will follow. Requests from other systems will be kept for when they're supported.

Which version is this?

sAI 0.2.0, an early preview. Run sai --version to see the version you have.

Can I use it on two computers?

Each license works on the computer whose code you sent. For another computer, just request a second license.

I got a new laptop or reinstalled my system.

Your laptop code changes. Send a new request with the new code and mention it — we'll replace your license.

Does it cost anything?

Access is free during the preview. Model usage is billed by the providers whose keys you use — with free-tier keys, most work costs nothing.

Is my code sent anywhere?

Only to the AI model providers whose keys you configure, as part of each request. sAI has no server of its own.
